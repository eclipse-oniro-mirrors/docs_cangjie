| 1    | 客户化写作基本要求 | **写作中，请变身开发者，对于开发者使用该组件时所需的使用场景、参数选取原则、开发建议/经验、示例等信息进行清晰描述，达到指导开发者顺利使用本组件进行开发的目标。** |
| 2    | 上传路径           | markdown文件：docs/zh-cn/application-dev/reference/arkui-cj/<br>图片和动态图路径：docs/zh-cn/application-dev/reference/arkui-cj/figures，并在markdown文件中引用（如：!\[](figures/xxx.png)或!\[](figures/xxx.gif)）。 |
| 3    | 文件命名           | 一个UI组件对应一篇组件文档，文件名称为组件名，全小写，格式为：**cj-组件所属目录-组件名.md**。<br>示例：<br>基础组件Text，属于“文本与输入”目录，文件命名为：cj-text-input-text.md<br>容器组件List，属于“滚动与滑动”目录，文件命名为：cj-scroll-swipe-list.md |
| 4    | 目录修改           | 增删文件时，需要修改对应的`README`和`website`，即`docs/zh-cn/application-dev/reference/arkui-cj/README_zh.md`和`docs/zh-cn/application-dev/website.md`。 |
| 5    | 文档结构           | - 导入模块<br>- 子组件<br>- 创建组件<br>- 通用属性/通用事件<br>- 组件属性<br>- 组件事件<br>- 基础类型定义<br>- 示例代码<br>API按上述标题分类展示，内部按API字母序，请注意排列。 |
| 6   | 其他       | 其余注意事项请参考[系统API总体写作说明](./cj-apis-template.md#总体写作说明)。 |

# 文档标题

> *写作说明*
>
> 1. **文档标题**：组件名称，即，使用可以概括本组件功能的“中文短语”或“中文短语（组件英文名称）”作为标题；但如果部分概念使用英文更便于开发者理解，可直接使用英文，如Button、Slider等。一般对应于cj.d中与文件名结尾同名的class名称。
> 2. **标题层级**：
>     - 二级标题：组件使用及功能。如：导入模块、子组件支持情况、创建组件的方法、通用属性/事件支持情况、组件属性方法、组件事件方法、组件用到的相关基础类型、组件完整示例代码等。
>     - 三级标题：组件相关功能的API。如：组件类的构造函数（创建组件的方法）、组件类的普通成员函数（组件属性方法）、组件类事件相关的函数（组件事件方法）等。
> 3. 每篇UI组件API文档以组件为单元进行撰写。

<!--Del-->
> **说明：**
>
> 当前为Beta阶段。
<!--DelEnd-->

组件描述。此处对该组件的定义、功能、使用场景、使用建议进行描述，采用如下固定句式。

**（组件介绍）** xxx是xxx。

**（功能描述，必选）** 提供xxx能力，包括xxx、xxx等，用于xxx。（当组件名不够语义化时，推荐此句式）/xxx组件，用于xxx、xxx。（当组件名已经表达了清晰的语义时，推荐此句式）

**（使用场景，可选）** 当需要xxx时，使用本组件xxx。

**（使用建议或注意事项，可选）** 本组件可与xxx联合使用，以提升开发效率……。

**举例1**：Marquee

跑马灯组件，用于滚动展示一段单行文本，仅当文本内容宽度超过跑马灯组件宽度时滚动。

**举例2**：SideBarContainer

提供侧边栏可以显示和隐藏的侧边栏容器，通过子组件定义侧边栏和内容区，第一个子组件表示侧边栏，第二个子组件表示内容区。

## 创建组件

> *写作说明*
>
> 1. 若该组件类有公开的构造函数，则必选；如果没有公开的构造函数可删除此二级标题，并将正确获取该组件的方式写在开头组件介绍，如“本组件需通过调用xxx获取”。
> 2. 每个构造函数新建一个三级标题。
> 3. 其余内容规范参考普通函数的写作规范[func](./cj-apis-template.md#func-xxxtype1-type2-)。

### init(Type1, Type2, ...)

```cangjie
public init(param1: Type1, param2: Type2)
```

**功能：** 根据(param1含义)和(param2含义)创建一个xx组件。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** xx

**参数：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| ----- | --- | ---- | --- | --- |
| param1 | Type1 | 是 | - | 参数描述。 |
| param2 | Type2 | 是 | - | 参数描述。 |
